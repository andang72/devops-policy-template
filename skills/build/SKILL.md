# Build

Use during implementation.

- Build incrementally from the approved spec.
- Keep each change small enough to review.
- Follow existing project conventions and policy files.
- Avoid unrelated refactors, broad rewrites, and speculative options.
- Preserve behavior outside the requested scope.
- Record validation commands and results as the work progresses.
